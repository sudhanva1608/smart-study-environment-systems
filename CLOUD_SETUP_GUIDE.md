# ☁️ Complete Cloud Setup & Login Guide

This guide walks you step-by-step through setting up your **100% Free Cloud Services** for the **Smart Study Environment Sensing System (SSES)**.

---

## 1. Set Up HiveMQ Cloud (Free MQTT Broker)

### 📌 Step 1: Create a HiveMQ Cloud Account
1. Open [https://www.hivemq.com/cloud/](https://www.hivemq.com/cloud/) in your browser.
2. Click **"Sign Up Free"** (No credit card required).
3. Verify your email and log in to the HiveMQ Console.

### 📌 Step 2: Create Your Free Cluster
1. Click **"Create Cluster"** -> Select **HiveMQ Cloud Serverless (Free)**.
2. Wait a few seconds until your cluster status says **Active**.
3. Note down your **Cluster URL** (e.g. `xxxxxxxx.s1.eu.hivemq.cloud`).

### 📌 Step 3: Add Credentials
1. In your Cluster menu, click on the **"Access Management"** tab.
2. Click **"Add Client"**.
3. Create a username and password (e.g., Username: `sses_user`, Password: `Password123!`).
4. Set Permissions to **Publish & Subscribe**.
5. Click **"Save"**.

---

## 2. Set Up Supabase (Free Cloud Database)

### 📌 Step 1: Create a Supabase Account
1. Open [https://supabase.com/](https://supabase.com/) in your browser.
2. Click **"Start your project"** (Sign in with GitHub or Email).

### 📌 Step 2: Create a New Project
1. Click **"New Project"**.
2. Set Name: `SSES_Database` and enter a strong database password.
3. Select a region close to you (e.g., `South Asia (Mumbai)`).
4. Click **"Create new project"**.

### 📌 Step 3: Create the Telemetry Table
1. On the left sidebar menu, click **SQL Editor**.
2. Click **"New query"**.
3. Paste the following SQL script:
```sql
CREATE TABLE IF NOT EXISTS readings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  temperature FLOAT NOT NULL,
  humidity FLOAT NOT NULL,
  light INT NOT NULL,
  air_quality INT NOT NULL,
  status TEXT NOT NULL,
  light_label TEXT NOT NULL,
  recorded_at TIMESTAMPTZ DEFAULT NOW()
);
```
4. Click **"Run"** (Ctrl + Enter).

### 📌 Step 4: Copy API Keys
1. On the left sidebar, click **Project Settings** (gear icon) -> **API**.
2. Copy your **Project URL** (e.g., `https://xxxxxx.supabase.co`).
3. Copy your **anon public API Key** (`eyJh...`).

## 3. Configure Your Project Files

### 📌 Step 1: Backend `.env` Setup
In your project folder `backend/`, create or open the `.env` file and paste your credentials:

```env
PORT=3001

# Cloud MQTT Config (HiveMQ)
MQTT_BROKER_URL=tls://xxxxxxxx.s1.eu.hivemq.cloud:8883
MQTT_USERNAME=sses_user
MQTT_PASSWORD=Password123!
MQTT_TOPIC_TELEMETRY=sses/sensors/telemetry
MQTT_TOPIC_ACTUATOR=sses/actuators/leds

# Cloud DB Config (Supabase)
SUPABASE_URL=https://xxxxxx.supabase.co
SUPABASE_ANON_KEY=eyJh...

# Python ML Microservice
ML_SERVICE_URL=http://localhost:5000
```

### 📌 Step 2: ESP32 Sketch Setup
In `SSES_ESP32/SSES_ESP32.ino`:
```cpp
const char* WIFI_SSID   = "YOUR_WIFI_NAME";
const char* WIFI_PASS   = "YOUR_WIFI_PASSWORD";

const char* MQTT_BROKER = "xxxxxxxx.s1.eu.hivemq.cloud"; // Your HiveMQ host
const int   MQTT_PORT   = 8883;
const char* MQTT_USER   = "sses_user";
const char* MQTT_PASS   = "Password123!";
```

## 4. How to Start Everything

Open **3 Terminal windows** in VS Code:

### 🖥️ Terminal 1 (Python ML Microservice):
```bash
cd backend
python ml_service.py
```
*(You will see: `INFO: Uvicorn running on http://0.0.0.0:5000`)*

### 🖥️ Terminal 2 (Node.js Gateway Backend):
```bash
cd backend
node server.js
```
*(You will see: `[MQTT] ✅ Connected to Cloud MQTT Broker!`, `[CloudDB] ☁️ Connected to Cloud Supabase DB`)*

### 🖥️ Terminal 3 (React Dashboard):
```bash
cd frontend
npm run dev
```
*(Open http://localhost:5173 in your browser to view your live AI Dashboard!)*
